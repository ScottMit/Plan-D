Physical Robot

Give the creature a physical body. Tick the box, connect your Pardalote board (WiFi or USB), then set up the actuators you've wired. Each gesture plays on the actuators whose name matches its lanes, as well as the on-screen face. Changes save in this browser.

Robot
Response Schema

The robot asks Gemini for structured output: every reply must match this JSON schema, and the API enforces it — so the chosen gesture is always one that exists and the levers are always present. You edit the schema in the code (brain.js → responseSchema) and give each field an effect with a handler of the same name in actions.js (speech is spoken; gesture is played, reading scale/speed/gaze); a field with no handler is ignored. It updates below as you add or hide gestures.

System Prompt

The three parts below are joined, with your authored gesture list inserted between “Reply style” and “Output rules”, and sent to Gemini as the system instruction. Changes save in this browser and take effect on the next turn.
