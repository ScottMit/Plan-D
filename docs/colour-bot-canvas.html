Gemini: Colour Bot

 

Turn Language into Structured Commands

 

A Large Language Model (LLM) like Google Gemini is the AI behind tools such as ChatGPT. In these three projects a p5.js sketch sends the model plain English and gets back a small answer it can act on: the model chooses the colours of three shapes on the canvas. Project 2 adds memory so follow-up instructions work; Project 3 lets you speak instead of type.

The key idea is structured output. Left alone an LLM replies with prose, which is hard for code to use. Instead we force the model to reply with JSON in an exact shape we define, so your sketch always receives clean values (like r, g, b numbers) it can read directly.

How it connects: a browser can't call Gemini directly, so requests go through a small relay your teacher has put online: your sketch → the relay → Gemini → JSON back. Every request carries your own Gemini key, so usage is billed to your own free quota.

Setup

  1. Get a free Gemini key at https://aistudio.google.com/apikey — click Create API key and copy it. Keep it private, like a password.
  2. Make a p5.js sketch, download it, and open the folder in VS Code — the same VS Code + Live Server workflow you used for Pardalote. You will edit index.html, style.css, and sketch.js.
  3. In sketch.js, paste your key into GEMINI_KEY and set PROXY_URL to the class relay.
  4. Click Go Live (Live Server) to run it. Serving over a local server matters — opening the file directly can block the request.

Project 1 — Colour Bot

Three shapes start grey. Type an instruction such as “make the circle red and the triangle blue” and Gemini replies with the colours to use. A line above the input shows “enter your prompt”, then “thinking…” while it waits.

Your index.html loads p5 from the web and your sketch.js:

The whole program is in sketch.js:

// ---- Your settings ----
const GEMINI_KEY = "PASTE_YOUR_OWN_GEMINI_KEY_HERE";
const PROXY_URL  = "https://gemini-relay.YOUR-SUBDOMAIN.workers.dev";
const GEMINI_MODEL = "gemini-3.1-flash-lite";

// What we tell the model to do (in plain words).
const SYSTEM_PROMPT =
  "You control the colour of 3 shapes on a screen: a circle, a square, and a triangle. " +
  "Read what the user says and, for each shape, return an object with change, r, g, and b. " +
  "If the user clearly asks to change a shape's colour, set change to true and give the colour " +
  "as Red, Green, and Blue integers in the range 0-255. If there is no clear instruction to change " +
  "a shape's colour, set change to false for that shape (still include r, g, b - any values, e.g. 0, " +
  "as they will be ignored). Do not provide any explanation or descriptive text.";

// The structured-response schema. Gemini is forced to reply with JSON in
// exactly this shape: one object per shape, each with change + r/g/b integers.
const RESPONSE_SCHEMA = {
  type: "object",
  properties: {
    circle: {
      type: "object",
      properties: {
        change: { type: "boolean" },
        r: { type: "integer", minimum: 0, maximum: 255 },
        g: { type: "integer", minimum: 0, maximum: 255 },
        b: { type: "integer", minimum: 0, maximum: 255 }
      },
      required: ["change", "r", "g", "b"]
    },
    square: {
      type: "object",
      properties: {
        change: { type: "boolean" },
        r: { type: "integer", minimum: 0, maximum: 255 },
        g: { type: "integer", minimum: 0, maximum: 255 },
        b: { type: "integer", minimum: 0, maximum: 255 }
      },
      required: ["change", "r", "g", "b"]
    },
    triangle: {
      type: "object",
      properties: {
        change: { type: "boolean" },
        r: { type: "integer", minimum: 0, maximum: 255 },
        g: { type: "integer", minimum: 0, maximum: 255 },
        b: { type: "integer", minimum: 0, maximum: 255 }
      },
      required: ["change", "r", "g", "b"]
    }
  },
  required: ["circle", "square", "triangle"]
};

// ---- state ----
let promptInput;
let feedback;
let shapeColours = {
  circle:   [200, 200, 200],
  square:   [200, 200, 200],
  triangle: [200, 200, 200]
};
let thinking = false;

function setup() {
  createCanvas(400, 400);

  feedback = createDiv("enter your prompt");

  promptInput = createInput("");
  promptInput.attribute("placeholder", "e.g. make the circle red and the triangle blue");
  promptInput.size(360);
  promptInput.elt.addEventListener("keydown", (e) => { if (e.key === "Enter") ask(); });

  const sendBtn = createButton("Send");
  sendBtn.mousePressed(ask);
}

function draw() {
  background(0);
  noStroke();

  fill(shapeColours.circle[0], shapeColours.circle[1], shapeColours.circle[2]);
  circle(100, 100, 100);

  rectMode(CENTER);
  fill(shapeColours.square[0], shapeColours.square[1], shapeColours.square[2]);
  rect(300, 100, 100, 100);

  fill(shapeColours.triangle[0], shapeColours.triangle[1], shapeColours.triangle[2]);
  triangle(300, 250, 350, 340, 250, 340);
}

// Type something, send it to Gemini, then recolour the shapes.
async function ask() {
  const message = promptInput.value().trim();
  if (!message || thinking) return;

  thinking = true;
  feedback.html("thinking...");
  const answer = await askGemini(message);
  thinking = false;
  feedback.html("enter your prompt");

  console.log("answer:", answer);   // see the JSON in the console (F12)

  if (answer) {
    applyAnswer(answer);
  }
}

// Recolour each shape the model marked change:true; leave the others alone.
function applyAnswer(answer) {
  for (const name of ["circle", "square", "triangle"]) {
    const s = answer[name];
    if (s && s.change) shapeColours[name] = [s.r, s.g, s.b];
  }
}

// Send one message to Gemini through the relay and return the parsed answer.
async function askGemini(userText) {
  if (GEMINI_KEY.includes("PASTE_") || PROXY_URL.includes("YOUR-SUBDOMAIN")) {
    console.warn("Edit GEMINI_KEY and PROXY_URL at the top of sketch.js first.");
    return null;
  }
  try {
    const res = await fetch(PROXY_URL, {
      method: "POST",
      headers: { "Content-Type": "application/json", "x-goog-api-key": GEMINI_KEY },
      body: JSON.stringify({
        model: GEMINI_MODEL,
        systemInstruction: { parts: [{ text: SYSTEM_PROMPT }] },
        contents: [{ parts: [{ text: userText }] }],
        generationConfig: {
          responseMimeType: "application/json",
          responseSchema: RESPONSE_SCHEMA
        }
      })
    });

    const data = await res.json();
    if (!res.ok) { console.error("Gemini error", res.status, data); return null; }

    const jsonText = data?.candidates?.[0]?.content?.parts?.[0]?.text;
    return JSON.parse(jsonText);
  } catch (e) {
    console.error("Request failed:", e);
    return null;
  }
}

How it works:

  • SYSTEM_PROMPT is the instruction the model always follows. RESPONSE_SCHEMA is the strict shape the reply must fill: each shape has a change flag and r, g, b integers 0–255.
  • ask() reads your text and awaits the reply (that's why it is async — it pauses until the answer arrives). applyAnswer() stores the new colour for any shape marked change: true, and draw() paints them.
  • askGemini() POSTs to the relay with your key. Gemini's JSON arrives as a string inside data.candidates[0].content.parts[0].text; JSON.parse() turns it into an object. Any failure is logged and returns null, so the sketch never crashes.
  • Swap GEMINI_MODEL for another name to compare models. gemini-2.5-flash is retired and returns a 404 — a useful error to see.

Project 2 — Adding Memory

The basic bot forgets everything between messages, so “now make it green” means nothing. This version keeps a running conversation and resends it every time, so the model has context. Now this works: “make the circle blue” → “now make it green” → “now make the square the same colour”.

Start from Project 1. Add one sentence to the end of SYSTEM_PROMPT (before “Do not provide…”):

  "Use the conversation so far to remember each shape's current colour and to " +
  "resolve references like 'it', 'that one', or 'the same colour'. " +

Add the memory store next to the other state variables:

// THE MEMORY: the conversation so far. We resend it every time, but only
// keep the last MAX_CALLS exchanges so it doesn't grow forever.
const MAX_CALLS = 10;
let conversation = [];

Change ask() to add each turn to the conversation and send the whole thing:

async function ask() {
  const message = promptInput.value().trim();
  if (!message || thinking) return;

  // add your new message to the running conversation, then send the WHOLE thing
  conversation.push({ role: "user", parts: [{ text: message }] });

  thinking = true;
  feedback.html("thinking...");
  const answer = await askGemini(conversation);
  thinking = false;
  feedback.html("enter your prompt");

  console.log("answer:", answer);

  if (answer) {
    applyAnswer(answer);
    // remember the model's reply too, so later turns have context
    conversation.push({ role: "model", parts: [{ text: JSON.stringify(answer) }] });
    // keep only the last MAX_CALLS exchanges (drop the oldest user+model pairs)
    while (conversation.length > MAX_CALLS * 2) conversation.shift();
  } else {
    // the request failed - drop the user turn so the history stays valid
    conversation.pop();
  }
}

Finally, change askGemini to accept and send the whole conversation. The function is identical to Project 1 apart from two lines:

async function askGemini(contents) {   // was (userText)
  // ...everything else is the same, except the body line:
        contents: contents,                  // was: [{ parts: [{ text: userText }] }]

How the memory works:

  • conversation is a list of turns in the format Gemini expects: { role: "user" or "model", parts: [{ text }] }.
  • Before sending we push your message as a "user" turn, then send the entire list. When the reply arrives we push it on as a "model" turn — that's how the model knows what “it” or “the same colour” refers to.
  • The one line that gives memory is contents: contents instead of a single message.
  • shift() drops the oldest pair once you pass 10 exchanges, so the list stays a sensible size and always begins with a "user" turn (which Gemini requires). Reload the page to start a fresh conversation.

Project 3 — Adding Voice

Now you can speak your commands instead of typing them. The browser has built-in speech recognition (the Web Speech API) that turns your voice into text — we drop that text into the same input and send it, so everything else, including the memory, keeps working. Spoken follow-ups like “now make it green” work too.

Start from Project 2. Add one line at the very end of setup():

  setupVoice();   // add the "Speak" button (browser speech-to-text)

Then add this new function:

// ---- voice input (Web Speech API, Chrome) ----
let recognition;

function setupVoice() {
  // The browser's speech recognition. Chrome exposes it as webkitSpeechRecognition.
  const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
  if (!SpeechRecognition) {
    createDiv("(voice input needs Google Chrome)");
    return;
  }

  recognition = new SpeechRecognition();
  recognition.lang = "en-US";
  recognition.interimResults = false;   // wait for the final result, not live guesses

  // When your speech has become text, put it in the input and send it.
  recognition.onresult = (e) => {
    const heard = e.results[0][0].transcript;
    promptInput.value(heard);
    ask();
  };
  recognition.onerror = () => { feedback.html("enter your prompt"); };
  recognition.onend   = () => { if (!thinking) feedback.html("enter your prompt"); };

  const speakBtn = createButton("Speak");
  speakBtn.mousePressed(() => {
    if (thinking) return;
    feedback.html("listening...");
    recognition.start();   // the browser may ask for microphone access
  });
}

How the voice works:

  • Press Speak, and recognition.start() listens for one command. When it has the words, onresult puts them in the input and calls ask() — the exact same path as typing, so memory still works.
  • Voice recognition runs in Google Chrome, and the browser will ask for microphone permission the first time.
  • If the browser has no speech support, a small note appears instead of the Speak button, and you can still type.

Troubleshooting

When something doesn't work, open the browser console first: press F12 (or right-click → Inspect) and click Console. The code prints the real error there.

  • Nothing happens / the shapes stay grey. If the console says Edit GEMINI_KEY and PROXY_URL…, you haven't set your key or the relay URL at the top of sketch.js. Otherwise, read the error the console prints.
  • Gemini error 404. The model name is wrong or retired. gemini-2.5-flash no longer works on new keys — use a current one such as gemini-3.1-flash-lite or gemini-3.6-flash.
  • Gemini error 429. You've hit your free daily quota or sent requests too quickly. Wait a little — it resets. Each key has its own quota.
  • Gemini error 400. Usually a typo in RESPONSE_SCHEMA. Compare it carefully with the example.
  • 403 / API key not valid. The key is wrong or has been blocked. Re-copy it from AI Studio, or delete and regenerate it. Never publish a key.
  • A CORS or network error. Run the page with Live Server (http://localhost…), not by double-clicking the file (file://). The request is blocked otherwise.
  • Project 3: Speak does nothing. Voice recognition works in Google Chrome. Allow microphone access when asked, and serve with Live Server. In other browsers you'll see a note instead of the button — you can still type.
  • Project 3: it heard the wrong words. Speech-to-text isn't perfect. Speak clearly, or just type the command instead.
